# Оплата и задолженность по услугам

## Настройка колонок

Откройте **Настройки → Колонки отчётов**. Раздел доступен сотруднику с правом управления тарифами, включая бухгалтера.

Сначала выберите «Отчёт»: «Оплата по услугам», «Задолженность — начисленная» или «Задолженность — просроченная». У каждого свой независимый набор колонок, порядок и привязки услуг; эти настройки используются также в его XLSX/PDF. При обновлении прежняя общая конфигурация становится начальной для всех трёх отчётов, после чего изменения одного не влияют на остальные.

Выберите колонку слева, задайте её название и отметьте услуги справа. Можно создать до 20 колонок для каждого отчёта, изменить их порядок стрелками и удалить ненужные. Нажмите «Сохранить колонки»: конфигурация применяется только к выбранному отчёту, не изменяя исходные начисления и платежи. Несохранённые правки сохраняются на экране при переключении отчётов до закрытия раздела; для записи каждого набора нажмите «Сохранить колонки» отдельно.

Количество назначенных услуг показано отдельным бейджем рядом с названием колонки. Если услуга назначена другой колонке, справа от её названия показан светло-зелёный бейдж «Колонка» с названием этой колонки; выбрать такую услугу повторно нельзя.

Услуга назначается одной колонке. Если несколько услуг используют один вид поступления, назначайте их одной колонке: старые финансовые записи различают только вид поступления. Ставки тарифа и их периоды менять для настройки отчёта не нужно.

«Прочее» создаётся автоматически для неназначенных услуг, начального долга, сборов, нерегулярных операций и штрафов, не включённых в отдельную колонку. Колонка скрывается, если соответствующих сумм нет. Архивные услуги остаются доступны для классификации исторических записей.

Если настройки были изменены другим сотрудником, текущие правки сохраняются на экране, но запись отклоняется. Кнопка «Отменить правки и перечитать настройки» загружает актуальную конфигурацию.

## Оплата по услугам

Откройте **Отчёты → Оплата по услугам**. Пустая «Дата с» означает всю историю учёта. «Дата по» по умолчанию — последний день текущего месяца. Обе границы включаются в отчёт. При необходимости найдите и выберите гараж.

Оплаты показаны по фактической дате платежа, от новых дней к старым. Общая оплата распределяется по услугам согласно действующим распределениям; нераспределённый остаток относится к «Прочее». Отменённые платежи исключаются.

Строки подгружаются при прокрутке без отдельной кнопки и счётчика. Для прокрутки с клавиатуры перейдите Tab в область строк и используйте стрелки или Page Down. Заголовки и итог по всему фильтру закреплены. Итог дня показан после загрузки всех строк этого дня. Общий итог учитывает весь выбранный период, а не только видимые строки; повторяющейся подписи периода и суммы над таблицей нет.

## Задолженность

Откройте **Отчёты → Задолженность**, выберите дату и при необходимости гараж.

Переключатель «Начисленная / Просроченная» расположен сразу после выбора гаража. Таблица занимает оставшуюся высоту окна и сохраняет размер при пустом результате. Полные итоги закреплены внизу; повторяющаяся подпись даты и суммы над таблицей не отображается.

- «Начисленная» — непогашенные начисления, включая те, срок оплаты которых ещё не истёк.
- «Просроченная» — непогашенные начисления, для которых на указанную дату наступила просрочка. Начисления с неподтверждённым сроком оплаты не включаются в просрочку.

Учитываются начальный долг/просрочка и начальный аванс, действующие распределения оплат до даты среза и свободные оплаты. Свободный остаток сначала погашает входящий долг, затем старые начисления. Начальные баланс и просрочка не складываются как два независимых долга. Гаражи без задолженности не показаны.

Отчёт использует действующие финансовые записи и их даты. Он не восстанавливает из истории изменения, отменённые после выбранной даты, и не восстанавливает старые значения впоследствии изменённого начального баланса.

## Выгрузки

Таблицы оплаты и задолженности используют оформление остальных отчётов. Нижняя строка «ИТОГО» показывает полные суммы по выбранному фильтру, независимо от количества загруженных и видимых строк.

Кнопки XLSX и PDF выгружают весь выбранный фильтр, независимо от загруженных строк. Максимум — 5000 строк: при превышении выберите гараж или более узкий период. Числовые номера гаражей выгружаются числами с защитой точности Excel; буквенные номера остаются текстом. Объединённых ячеек нет.

Если настроено больше семи колонок услуг, PDF разбивается на горизонтальные части с повторением даты, гаража и общего итога. Никакие колонки не теряются; XLSX сохраняет единую широкую таблицу.

## Выбор гаражей в тарифе

В карточке услуги откройте «Гаражи» и включите «Только для выбранных гаражей». На широком экране гаражи показаны в четыре колонки, на небольшом — в три или две. При прокрутке подгружается следующая часть списка. Поиск не сбрасывает выбранные гаражи; снять все отметки можно кнопкой «Снять выбор». Действующий предел — 100 выбранных гаражей.
