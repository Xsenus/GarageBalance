# Полная интеграция рабочих веток 04.09.2026

## Источники

- требование заказчика объединить все актуальные локальные и удалённые рабочие ветки в основную ветку;
- локальные ветки `master`, `xsenus/full-system-acceptance-audit` и их история;
- удалённые ветки `origin/master`, `origin/codex/ci-test-performance` после `fetch --all --prune`;
- открытые pull request, GitHub Actions, конфигурация автодеплоя и опубликованный VPS.

## Предположения и решения

- Основная ветка определена по `origin/HEAD`: `master`.
- Интеграция сначала собирается в `xsenus/full-branch-integration`; `master` обновляется только после полного локального gate.
- `origin/codex/ci-test-performance` является актуальной рабочей веткой: она содержит ускорение PostgreSQL-тестов/CI и безопасный первый запуск Docker, которых нет в `master`.
- Локальная `xsenus/full-system-acceptance-audit` содержит завершённый проверочный набор и исправление демонстрационной зарплатной выплаты.
- Производственная база не используется для разрушительных проверок; миграции и финансовые сценарии проверяются на чистой локальной PostgreSQL-базе.
- Рабочие ветки удаляются только после успешного push, CI/CD, проверки VPS и подтверждения достижимости их последних коммитов из `master`.

## Этап 5. Очистка веток и финальная сверка

- [ ] Подтвердить достижимость вершин завершённых рабочих веток из `master`.
- [ ] Удалить полностью влитые рабочие ветки локально и на GitHub, не затрагивая постоянные ветки.
- [ ] Выполнить повторный `fetch --prune`, проверить список веток и синхронизацию `master`/`origin/master`.
- [ ] Подтвердить чистое рабочее дерево и отсутствие оставленных задачей процессов/временных файлов.

## Definition of done

- Все актуальные уникальные изменения рабочих веток присутствуют в `master`, без дублирования и потерь.
- Полные backend/frontend, migration, security/privacy, Docker и production-build проверки проходят.
- GitHub Actions и автодеплой завершаются успешно; опубликованный VPS обслуживает commit `origin/master` и проходит smoke-check.
- Влитые рабочие ветки безопасно удалены локально и удалённо, а неоднозначные/постоянные ветки сохранены.
- Документация и «Что нового» соответствуют объединённому состоянию; рабочее дерево чистое.
